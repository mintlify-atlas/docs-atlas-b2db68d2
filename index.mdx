EduComSer Microservices is a Java-based backend platform composed of four independently deployable Spring Boot services orchestrated behind a single API Gateway. It is designed to handle product catalogs, order placement, and inventory stock verification — all protected by Keycloak JWT authentication and resilient to downstream failures through circuit breaking and retry logic.

## Services at a Glance

<CardGroup cols={2}>
  <Card title="Discovery Server" icon="satellite-dish" href="/services/discovery-server">
    Netflix Eureka registry — all services self-register and resolve via load-balanced URIs.
  </Card>
  <Card title="API Gateway" icon="shield-halved" href="/services/api-gateway">
    Spring Cloud Gateway with JWT enforcement, routing to all three business services.
  </Card>
  <Card title="Producto Service" icon="box" href="/services/producto-service">
    Create and list products stored in MongoDB. Exposes `POST /api/producto` and `GET /api/producto`.
  </Card>
  <Card title="Order Service" icon="cart-shopping" href="/services/order-service">
    Place orders with inventory validation, circuit breaker, and retry via Resilience4j.
  </Card>
  <Card title="Inventario Service" icon="warehouse" href="/services/inventario-service">
    Check SKU stock availability. Called internally by Order Service before confirming any order.
  </Card>
</CardGroup>

## How It Works

<Steps>
  <Step title="Start the Discovery Server">
    Launch the Eureka registry on port `8761` so all other services can register.
  </Step>
  <Step title="Start the Business Services">
    Start Producto Service (8081), Order Service (8082), and Inventario Service (8083) — each registers with Eureka automatically.
  </Step>
  <Step title="Start the API Gateway">
    The gateway on port `8084` routes incoming requests to services by path prefix and enforces JWT authentication via Keycloak.
  </Step>
  <Step title="Obtain a JWT and Call the API">
    Authenticate against your Keycloak realm, obtain a Bearer token, and call any endpoint through the gateway.
  </Step>
</Steps>

<Tip>
  All API calls must go through the API Gateway on port `8084`. Direct service ports are for local development only and bypass authentication.
</Tip>
